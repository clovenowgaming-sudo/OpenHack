# OpenHack-2.7

Android port of Prevter's OpenHack for Geometry Dash 2.2081 (Geode SDK 5.11.2).

Tap the small round **OH** button to open the menu. Drag the button to move it.

Features available on Android: Noclip (+limit), Start Pos Switcher, Auto Pickup Coins,
Instant Complete, Click Teleport, Frame Stepper, Random Seed, Show Hitboxes,
Smart StartPos, Auto Kill, Auto Safe Mode, Safe Mode, Menu Gameplay, Auto Save,
Speedhack, Display (FPS/TPS), Labels, Shortcuts, RGB Icons, Accurate Percentage,
Custom Wave Trail, Hide Pause, Hide Triggers, Music Unlocker,
Unlock Icons & Colors, Text Length Bypass, Character Filter Bypass.

Desktop-only features (Discord RPC, replay file dialogs, window options, keyboard-only
keybinds) were removed.
